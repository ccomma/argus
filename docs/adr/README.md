# 架构决策记录

本目录存放 Argus 的关键产品和技术决策。ADR 是共享决策记录，不属于某个 agent、skill 或工具。

ADR 不是默认上下文入口。新会话只有在当前任务涉及某个长期决策、替代方案或复核触发条件时，才读取对应 ADR。

需要 ADR 的情况：

- 存储方式选择。
- 事件 schema 或能力资产 schema 边界变化。
- 适配器契约（adapter contract）变化。
- 安全或治理策略变化。
- 会影响多个阶段的长期决策。

同时满足以下条件才创建 ADR：

- 难逆转：以后改变成本明显。
- 反直觉：没有背景的维护者会问为什么这样做。
- 真实权衡：存在可行替代方案，并且本次选择有明确理由。

不满足这些条件的内容，应写入当前阶段 handoff、技术设计、实现计划或验收记录。

创建新 ADR 时，从 `docs/templates/ADR_TEMPLATE.md` 复制结构，并按序号命名：

```text
ADR-0001-storage-choice.md
```
