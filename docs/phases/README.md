# 阶段执行包

本目录包含各阶段执行包。每个阶段在此保存一份精简的执行包，以便未来的会话无需加载所有历史设计文档即可承接。

每个阶段目录应包含：

- `HANDOFF.md`：该阶段的精简上下文入口。
- `IMPLEMENTATION_PLAN.md`：当前任务和排期。
- `ACCEPTANCE.md`：阶段验收清单和验证证据。

详细的产品、技术和测试文档可保留在：

- `docs/prd/`
- `docs/technical/`
- `docs/testing/`

阶段执行包通过链接引用这些文档，而不是复制其内容。

阶段执行包在阶段结束后保留。不要删除旧执行包；它们是历史工作的 token 高效证据链。
